# assets/

Pictures and files the website uses. Replace them with your own, keeping the same names (or update the path in `lib/personal_data/portfolio_content.dart`).

- `profile.png`: your photo (square, about 600 x 600)
- `projects/`: one logo per project (square PNG or SVG)
- `certificates/`: one picture per certificate (landscape PNG or JPG)
- `resume/Resume.pdf`: your resume
- `case_studies/`: optional PDFs shown from a project card
- `avatar.riv`, `vehicles.riv`: animation files used by the site background. Leave them.
